# Basic HTML Website

A clean, multi-page website built with semantic HTML to demonstrate fundamental web development concepts and best practices.

## 📋 Project Overview

This project implements the **Basic HTML Website** challenge from [roadmap.sh](https://roadmap.sh/projects/basic-html-website), creating a professional multi-page site structure using only HTML with minimal styling for demonstration purposes.

## 🌐 Live Demo

**[View Live Preview](https://roadmap-projects-by-juan-diki.vercel.app)**

## ✨ Features

- **Multi-page Architecture**: Organized structure with Home, Projects, Articles, and Contact pages
- **Persistent Navigation**: Consistent header and navigation across all pages
- **Semantic HTML5**: Proper use of semantic elements (`<header>`, `<nav>`, `<main>`, `<footer>`, etc.)
- **SEO Optimization**: Meta tags for search engine visibility and social sharing
- **Contact Form**: Functional form structure with proper input handling
- **Responsive Design Foundation**: Clean structure ready for CSS enhancement

## 📁 Project Structure

```
basic-html-website/
├── index.html          # Homepage
├── projects.html       # Projects showcase page
├── articles.html       # Articles/blog page
├── contact.html        # Contact form page
├── styles.css          # Basic styling
└── README.md           # Project documentation
```

## 🚀 Getting Started

1. Clone the repository:
```bash
git clone https://github.com/bautistaJuan/roadmap-projects-by-juan.git
cd frontend-projects/basic-html-website
```

2. Open in your browser:
```bash
# Simply open index.html in your browser, or use a local server
python -m http.server 8000  # Python 3
# or
npx http-server  # Node.js
```

3. Navigate through the pages using the menu

## 📝 Implementation Details

### Semantic Structure
- Used proper heading hierarchy (`<h1>`, `<h2>`, etc.)
- Implemented semantic landmarks (`<header>`, `<nav>`, `<main>`, `<footer>`)
- Organized content with article elements for blog posts

### Accessibility
- Descriptive link text
- Proper form labels
- Alt attributes for images

### SEO Best Practices
- Unique meta descriptions per page
- Proper title tags
- Open Graph tags for social sharing
- Canonical URLs (when applicable)
