# Single Page CV

Proyecto realizado como parte del roadmap de Frontend de roadmap.sh.

## Descripción

Este proyecto consiste en la creación de un CV de una sola página utilizando HTML semántico, aplicando buenas prácticas de estructura, SEO y configuración para compartir en redes sociales mediante Open Graph.

## Características

- HTML semántico
- Meta tags para SEO
- Open Graph tags
- Favicon personalizado
- Estructura preparada para estilos futuros
- Diseño pensado para impresión en formato A4

## Tecnologías

- HTML5
- CSS3

## Objetivos del proyecto

- Comprender la estructura semántica de HTML
- Aplicar meta etiquetas esenciales
- Configurar Open Graph para previews en redes sociales
- Preparar un documento listo para futuras mejoras visuales
